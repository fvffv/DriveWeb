Avalonia.OfficeViewer

基于 Vue-office 思想的 Native AOT 跨平台文档预览引擎设计方案

1. 项目目标

参考 Vue-office 系列项目思想，实现基于 C# + Avalonia UI + Native AOT 的跨平台文档预览框架。

  • 支持 DOCX
  • 支持 XLSX
  • 支持 PPTX
  • 支持 PDF
  • 支持 Windows/Linux/macOS/Android/iOS
  • 不依赖 Office
  • 不依赖 COM
  • 不依赖 WebView
  • 支持 Native AOT

3. Native AOT要求

  • 禁止 Activator.CreateInstance
  • 禁止 Assembly.Load
  • 禁止 Type.GetType
  • 避免运行时反射
  • 所有类型必须编译期可分析
